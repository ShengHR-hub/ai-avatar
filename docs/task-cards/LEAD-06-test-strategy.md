# LEAD-06：测试矩阵与验收门禁

## 会话目的

设计正式开发的测试策略和最终验收标准，重点覆盖资金、异步任务、权限和外部调用异常。

## 必须覆盖

- Schema 空库迁移和约束；
- 邀请码并发兑换和身份恢复；
- 点数预留、消费、释放、重复调用和事务回滚；
- 任务非法状态、重试、恢复和重复回调；
- Provider 错误、超时、未知结果、成本记录；
- 上传权限、签名 URL、分享权限和生命周期清理；
- 本地完整 E2E 和移动端关键流程。

## 输出

- 测试矩阵；
- 测试数据和 Mock 场景；
- 每张 ENG 卡的验收命令；
- 发布前阻断条件；
- 回归清单。

## 不负责

不替工程 Agent 编写普通实现，不因为测试困难而降低账务或安全验收标准。

## 审核门禁

所有 P0 场景都有可执行测试和明确期望结果，才可作为 `ENG-10` 的验收依据。

## 下一步

工程 Agent 完成 `ENG-10` 后，按本卡逐项执行；结果交给 `LEAD-07`。
